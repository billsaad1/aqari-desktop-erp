# مثبت نظام العقارات والمحاسبة على Windows

يُبنى التطبيق بنسخة Windows Release ثم يحوله Inno Setup إلى `Aqari-ERP-Setup.exe`. يثبت المثبت البرنامج للمستخدم الحالي دون طلب صلاحيات مدير، وينشئ اختصارًا في قائمة ابدأ واختصارًا على سطح المكتب افتراضيًا، مع استخدام شعار المؤسسة كأيقونة للتطبيق والمثبت.

في البناء المحلي على Windows:

1. ثبّت Flutter وفعّل دعم Windows Desktop.
2. ثبّت Inno Setup 6.5 أو أحدث لاستخدام ملف الترجمة العربية المضمّن.
3. من جذر المشروع شغّل `flutter pub get` ثم `flutter build windows --release`.
4. شغّل `ISCC.exe installer\aqari_setup.iss`.
5. ينتج الملف `build\windows\installer\Aqari-ERP-Setup.exe`.

يضيف AppVeyor الخطوات نفسها وينشر ملف المثبت كأحد مخرجات البناء، إلى جانب ملفات النسخة المحمولة. قاعدة البيانات محفوظة في مجلد مستندات المستخدم (`Documents\AbdullahAlNaqeebERP`) وليست داخل مجلد التثبيت؛ لذلك لا يحذف إلغاء تثبيت البرنامج بيانات المنشأة.
